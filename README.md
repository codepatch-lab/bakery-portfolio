
# こむぎ日和 | ベーカリーサイト

架空のベーカリー「こむぎ日和」をイメージして制作したWebサイトです。

## デモサイト

https://codepatch-lab.github.io/bakery-portfolio/

## 使用技術

- HTML
- CSS
- GitHub Pages

## 制作内容

- ヘッダーとナビゲーションの作成
- メインビジュアルの配置
- 商品紹介カードの作成
- 店舗紹介・アクセス情報の掲載
- スマートフォンにも対応したレイアウト
- ページ内リンクとトップへ戻るボタンの設置

## 工夫した点

- パン屋さんらしい温かみのあるデザイン
- 画像と文字の配置を調整し、見やすさを意識
- 画面サイズに合わせてレイアウトが変わるようにCSSを調整

## 補足

このサイトは学習・ポートフォリオ用の架空の店舗サイトです。
掲載画像にはAI生成画像を使用しています。
