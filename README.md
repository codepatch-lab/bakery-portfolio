# こむぎ日和 | ベーカリーサイト

架空のベーカリー「こむぎ日和」をイメージして制作したWebサイトです。

HTML・CSS・JavaScriptを使用し、店舗紹介だけでなく、商品を選んで買いたいリストを作成できる機能を実装しました。

## デモサイト

https://codepatch-lab.github.io/bakery-portfolio/

## 使用技術

- HTML
- CSS
- JavaScript
- GitHub Pages

## 実装した機能

- ヘッダー・ナビゲーション
- メインビジュアル
- JavaScriptによる商品カードの自動生成
- 商品カルーセル（PCは3商品、スマートフォンは1商品表示）
- 買いたいパンリストへの追加・個別削除・一括削除
- 選択した商品の合計金額の自動計算
- localStorageを利用したリストの保存
- レスポンシブデザイン
- ページ内リンク・トップへ戻るボタン

## 工夫した点

### 1. 商品データの一括管理

商品名・説明・価格・画像をJavaScriptの配列で管理し、商品カードを自動生成するようにしました。

商品を追加する際にHTMLを直接編集する必要がなく、データを追加するだけで表示内容を更新できます。

### 2. 買いたいパンリスト

気になるパンを選択すると、買いたいリストに追加される機能を実装しました。

リストでは商品名・価格・合計金額を確認でき、商品ごとの削除や一括削除にも対応しています。

また、localStorageを使用することで、ページを再読み込みしても選択状態が保持されるようにしました。

### 3. レスポンシブ対応

PCとスマートフォンで商品カードの表示枚数を切り替えています。

スマートフォンでも操作しやすいように、カルーセルの矢印やリストのレイアウトを調整しました。

### 4. デザイン

パン屋さんらしい温かみのある配色を意識し、画像・文字・余白のバランスを調整しました。

## 制作目的

HTML・CSSの復習とJavaScriptの学習を目的として制作しました。

商品データの管理、DOM操作、イベント処理、localStorageなどを実際のWebサイトに組み込みながら学習しました。

## 補足

このサイトは学習・ポートフォリオ用の架空の店舗サイトです。実在する店舗ではありません。

掲載画像にはAI生成画像を使用しています。
